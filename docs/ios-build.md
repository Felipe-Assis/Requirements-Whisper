# iOS pelo GitHub Actions

A execução de `iOS Build` usa um runner macOS ARM64 do GitHub, Ren’Py 8.5.3 e o complemento Renios oficial, ambos com SHA-256 fixado. O job recompila a árvore da revisão selecionada para dois destinos. O artefato `ios-unsigned` traz um IPA ARM64 para iPhone ou iPad, com SHA-256, pronto para assinatura. O artefato `ios-simulator-arm64` traz o `.app` do simulador, o SHA-256 e uma captura quando a inicialização no simulador termina.

A branch `build/ios` dispara o build a partir do download público de Windows da edição `1.8.1-epilogo`. O preparo verifica a edição do canal e os hashes do arquivo de versão e do epílogo antes de usar apenas a pasta `game/` do pacote. Assim a compilação do iOS usa dados já publicados e dispensa enviar novamente toda a arte ao GitHub. Quando o workflow estiver no `main` remoto, também poderá ser iniciado pelo menu Actions usando os arquivos daquela revisão. Os artefatos ficam disponíveis por sete dias.

Para um iPhone físico, o IPA precisa de assinatura e provisionamento. Para teste pessoal pelo Windows, o AltStore Classic oferece assinatura temporária com uma conta Apple e renovação a cada sete dias. A instalação e a execução nesse aparelho precisam ser verificadas. Distribuir por TestFlight ou App Store exige o Apple Developer Program. Nenhum certificado fica no Git.
